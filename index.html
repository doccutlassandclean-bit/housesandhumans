🗡️ Enter the Tavern

Sign in to your Open WebUI server to begin your adventure.

How to get your API key:
  1. Open your Open WebUI site in a browser tab and sign in.
  2. Click your profile name in the top-right corner.
  3. Choose Settings, then the Account tab.
  4. Under API Keys, click Create new secret key if you don't have one, then copy it.
  5. Paste that key here. (If you don't see API Keys, an admin must enable them for your account.)

The tavern door stays shut until the connection succeeds.

⚙️ Settings

Get your key from Open WebUI: Settings → Account → API Keys.
